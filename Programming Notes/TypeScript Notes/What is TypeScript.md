- Use `tsc `   for compiling all typescript file in that  the folder
- use `tsc --watch `   to watch all TypeScript files for errors
- `tsconfig.json` file is used to configure TypeScript features ( where to to put complied code for example, where to put  distribution code , changing which version of JS it complies to ES6 , ES7 )
- use `tsc --init` to create a `tsconfig` file
