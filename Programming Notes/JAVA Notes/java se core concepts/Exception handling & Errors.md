# Exception are of three types

1.  compile time
2.  runtime
3.  logical error or bugs

- We debug the logical errors (test the input-output of our app)
- in Runtime we check using if conditions, try-catch
- in compile time, the compiler tells us about the error before running.

# Runtime Exception

## in Runtime we check using if conditions, try-catch

# Unchecked & Checked exception

- All Errors listed above are unchecked exception
- checked exception examples :- SQLException, IOException

the compiler we'll tell u and it's necessary to handle checked exception, the unchecked exception are optional to handle.
