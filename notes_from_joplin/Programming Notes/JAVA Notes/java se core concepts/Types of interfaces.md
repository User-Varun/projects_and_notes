# Three categories of Interfaces

1.  normal interface ( 2 or more methods)
2.  functional interface ( with only 1 method)
3.  Marker interface ( interface with no methods --> used for serialization)

Serialization :- say we have to store game's (save data) and load from memory, we do this same with java object (store info in hard-drive to retrieve at later) 

- serialization :- storing to hard-drive
- deserialization :- retrieving from or fetching from hard-drive 
- there are different type of marker interfaces example (Serializable)
