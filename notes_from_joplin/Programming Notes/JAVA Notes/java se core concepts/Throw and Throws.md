# Throw

- when we need to throw a exception (as a result of "if statements" or try-block or others) we use "Throw" 
- we can create our own exception, coz it's just a class but we must extend it to exception class and provide appropriate constructor

# Throws

- say i don't want to handle the exception in current method, i can use throws 
- the class that is calling this method will have to handle the exception now.
- this is called ducking the exception 
- usage example of these can be we want to handle simple error of multiple methods into one place
